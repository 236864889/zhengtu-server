# 入库规则（v0.3）

## 阶段结论
- `v0.1` 文档模板化较高，整体不建议直接入库。
- `v0.2/v0.3` 只对部分文档达到首批入库条件。

## 第一批可入库文件（白名单）
1. `docs/rag_sources/02_编译顺序与产物.md`
2. `docs/rag_sources/03_服务端启动顺序.md`
3. `docs/rag_sources/10_已修复编译问题记录.md`
4. `docs/rag_sources/modules/base.md`
5. `docs/rag_sources/modules/script.md`
6. `docs/rag_sources/modules/ScenesServer.md`
7. `docs/rag_index/入库规则.md`

## 暂缓策略
- 仓库根 README 与各目录 README：仅作导航索引，不作为第一优先入库语料。
- 仍偏模板化、事实密度不足的文档：暂缓入库。

## 过滤规则
- 无明确证据支撑的泛化段落不入库。
- 含“待确认”条目可入库，但必须带 `待确认` 标签，避免被当作确定事实。

## 切片建议
- 每片 500~1200 中文字，重叠 80~150 字。
- 优先按“编译链、启动链、模块依赖、修复记录”切片。
