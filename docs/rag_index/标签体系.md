# 标签体系

## 一级标签
- `service`：服务进程相关。
- `build`：编译、依赖、产物。
- `runtime`：启动、运行关系、排错。
- `config`：XML/Lua/脚本配置。
- `db`：数据库与账号体系。

## 二级标签示例
- `service:ScenesServer`、`service:GatewayServer`
- `build:makefile`、`runtime:start-order`
- `config:xml`、`config:lua`

## 待确认标签
- `port:unknown`、`db:schema-unknown`
