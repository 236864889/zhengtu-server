# 关键词索引矩阵（全局扫描）

> 扫描范围：`ztgame/` 下 `*.cpp/*.h/*.hpp/*.c/*.xml/*.lua/*.tbl/*.ini/Makefile/*.sh`。  
> 扫描命令关键字：`SUB_DIRS/CXXFLAGS/CXXLFLAGS/LIBS/TARGET/start.sh/start1.sh/stop.sh/main/init/final/validate/load/parse/reload/zService/zNetService/zSubNetService/zMNetService/Zebra::logger/logger->`。

## 1. 构建与产物关键词
- `SUB_DIRS`：`ztgame/Makefile`。
- `CXXFLAGS/CXXLFLAGS`：各服务目录 `Makefile`（如 `BillServer/Makefile`、`ScenesServer/Makefile` 等）。
- `ALL_TARGETS/TARGET`：各模块 Makefile 中的目标定义。

## 2. 启停脚本关键词
- `start.sh` / `start1.sh`：`ztgame/start.sh`、`ztgame/start1.sh`。
- `stop.sh`：`ztgame/stop.sh`。

## 3. 生命周期关键词
- `main(`：8 个核心服务入口文件均命中（Bill/FL/Gateway/Mini/Record/Scenes/Session/Super）。
- `init(` / `final(` / `validate(`：
  - 服务层：各 `*Service`。
  - 基类层：`zService`、`zSubNetService`、`zNetService`、`zMNetService`。

## 4. 配置与加载关键词
- `parse`：`SessionServer.cpp`、`SuperServer.cpp`、`BillServer.cpp` 等含 `zConfile` 解析。
- `load`：`SessionTask.cpp` 多业务分发、`GameConfigMgrX.cpp`、`fjconfig.cpp` 等。
- `reload`：`BillService::reloadConfig()` 等。

## 5. 日志关键词
- `Zebra::logger` 与 `logger->` 在基础库与服务模块均高频出现。
- 重点集中在：`base/z*` 网络与服务层、`SessionTask.cpp`、`BillServer.cpp`、`GatewayServer.cpp` 等。
