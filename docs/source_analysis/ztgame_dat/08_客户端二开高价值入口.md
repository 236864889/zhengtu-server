# 客户端二开高价值入口

## 1. 总体结论
- **最快出效果**：UI资源与界面脚本化配置、登录链路参数对接、图标/外观资源替换。
- **风险适中**：技能表现层（仅视觉部分）、小地图与场景UI提示。
- **高风险**：底层渲染库、协议头结构、场景核心同步逻辑。

## 2. 登录器与区服配置入口
- 关键文件：`GameAppation.cpp`、`NetAutoConnect.*`、`Client.cpp`、`GuiLogin*`、`GuiSelectCharDialog*`。
- `config.ini` 读取项已确认含：`Server/servername/loginAddress/loginPort/zone`、`other/version`、视频音频配置。
- `NetAutoConnect` 会根据登录成功包下发的 `pstrIP/wdPort` 重连游戏服，并发送版本+口令命令。
- 对接 C# 登录器建议：
  1) 写入 `config.ini`（servername/loginAddress/loginPort/zone/version）；
  2) 或通过命令行参数传入（`GameAppation` 支持 `__argc==5` 分支覆盖地址/端口/区号）。
- 不能乱改：`stPasswdLogonUserCmd`、`stUserVerifyVerCmd`、连接后 key 切换逻辑。

## 3. UI 与界面二开入口
- 代码入口：`Gui*.cpp`（登录、选角、背包、装备、商城、聊天、任务）。
- 资源入口：`datas.pak` 内 XML、`interfaces.gl/icons.gl/login.gl/items.gl`。
- 常见可改：按钮文案、图标帧号、布局坐标、开关逻辑。
- UI 改动同步项：
  - 对应 GL 图集帧存在性；
  - XML 控件 ID 与代码绑定一致；
  - 字体/分辨率适配。

## 4. 装备、外观、图标入口
- 数据结构：`table.h` 的 `ObjectBase_t`，查询入口 `GetObjectBase`。
- 显示路径：`GetItemPicLocation` + `items.gl`。
- 新装备/称号/外观可优先从“图标+展示”切入。
- 必须双端一致：`ObjectID/类型/可用等级/关键属性字段`，否则会出现“客户端显示正常、服务端判定异常”。

## 5. 技能、特效、魔法入口
- 结构与命令：`SkillBase_t/SkillLevelBase_t`、`stAttackMagicUserCmd`。
- 模块入口：`Magic/` + `Game.cpp` 中 magic 命令分发。
- 只改客户端可做：粒子、贴图、音效、部分表现时序。
- 必须双端同步：技能ID、伤害/目标类型、冷却与判定相关字段。

## 6. 地图、场景、NPC 入口
- 资源：`map.pak/datas.pak`。
- 代码入口：`GameScene*`、`Npc*`、`GuiMiniMap*`、`Magic/map.h/MapSurf`。
- 适合先做的小改：小地图样式、场景提示、非判定型特效展示。
- 需要完整工具链的改动：地形结构、阻挡、传送点/功能点批量改造。

## 7. 网络协议入口
- 客户端发包入口：`Client_SendCommand`（`Client.h` 宏，最终 `CClient::Send`）。
- 收包入口：`Client.cpp::Client_MsgThread` + `Game.cpp` 的 `Parse*Message`。
- 协议基准：`base/Command.h`、`base/MiniUserCommand.h`，客户端 `miniusercommand.h` 需同构。
- 不能随便改：结构体打包、字段顺序、`byCmd/byParam/subParam`、长度计算。
- 安全新增建议：新增命令号并保留旧逻辑兼容分支，不覆盖旧字段语义。

## 8. 推荐优先级表

| 优先级 | 二开方向 | 推荐入口 | 难度 | 风险 | 是否需要服务端同步 |
|---|---|---|---|---|---|
| P0 | 登录器对接/区服切换 | `GameAppation.cpp` + `NetAutoConnect.*` + `config.ini` | 低 | 中 | 部分需要 |
| P0 | UI视觉改版 | `Gui*.cpp` + `datas.pak` XML + `interfaces.gl/icons.gl` | 低~中 | 低~中 | 否 |
| P1 | 装备图标/外观展示 | `table.h` + `GetObjectBase` + `items.gl` | 中 | 中 | 是（ID/属性） |
| P1 | 技能表现优化 | `Magic/` + `Game.cpp` magic 分发 | 中~高 | 中~高 | 视改动而定 |
| P2 | 地图表现增强 | `GameScene*` + `GuiMiniMap*` + `map.pak` | 中~高 | 高 | 常常需要 |
| P3 | 协议扩展 | `Client.cpp` + `base/Command.h` + 服务端处理 | 高 | 高 | 是 |
| P3 | 底层渲染重构 | `RenderD3D8/engine` | 很高 | 很高 | 否（但全局影响大） |

## 9. 不建议初期修改的高风险入口
1. `RenderD3D8` 设备/纹理内存管理。
2. `engine` 的 Pack/Bitmap/Allocator 主路径。
3. `Game.cpp` 大型协议分发表核心逻辑。
4. `Magic` 中与战斗判定强绑定的坐标/阻挡逻辑。
