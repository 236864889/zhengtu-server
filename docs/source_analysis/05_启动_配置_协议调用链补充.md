# 启动 / 配置 / 协议调用链补充

## A. 启动主链（源码入口）
1. `main()` 创建 logger、解析参数/配置。
2. 调用 `*Service::init()` 初始化网络、任务池、跨服客户端。
3. 进入服务循环（由 `zService`/`zNetService` 系列驱动）。
4. 退出时调用 `*Service::final()` 清理资源。

## B. 配置加载链（已证实节点）
- `SessionServer.cpp`：`SessionConfile::parse("SessionServer")`。
- `SuperServer.cpp`：`SuperConfile::parse("SuperServer")`。
- `BillServer.cpp`：`BillService::reloadConfig()` 内 `parse("BillServer")`。
- `ScenesServer.cpp`：大量 `fjconfig::init*` 调用；底层在 `fjconfig.cpp` 中通过 `zXMLParser` 读取 XML。
- `GameConfigMgrX.cpp`：`GameConfigMgrX::init()` 使用 `zXMLParser`。

## C. 协议分发链（已证实节点）
- `SessionTask.cpp`：`verifyLogin/verifyConn` 后，对 `Cmd::stNullUserCmd` 执行大规模路由分发。
- `SuperServer/ServerTask.cpp`：包含 `Super/FL/Rolereg/Info/GmTool` 多命令头，承担多协议汇聚。
- `SceneTask.cpp` / `RecordTask.cpp` / `BillTask.cpp` / `GatewayTask.cpp`：均存在连接验证 + 任务处理模式。

## D. 数据库调用链（代表路径）
- 基础层：`zMysqlDBConnPool` + `zDatabase`。
- 业务层代表：`SessionServer/CUnion.cpp`、`CSept.cpp` 通过 `SessionService::dbConnPool->exeSelectLimit(...)` 发起查询。

## E. 二开改动高风险提醒
- `SessionTask.cpp`：命令分发面极广，修改需配套回归矩阵。
- `ScenesServer.cpp` + `fjconfig.cpp`：初始化链长，配置错误会导致启动失败。
- `SuperServer/ServerTask.cpp`：跨协议耦合高。

## F. 待确认
- `validate()` 在各服务主循环中的统一触发点与返回码语义。
- 端口/IP/DB 键值在各 Confile 中的完整字段映射表。
