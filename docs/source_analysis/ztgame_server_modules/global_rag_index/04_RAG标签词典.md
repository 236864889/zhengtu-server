- 生命周期：startup, init, lifecycle, shutdown, heartbeat, daemon
- 网络通信：socket, connection, gateway, session, scene, forward, dispatch
- 服务发现：super, serverlist, register, discover, route, service_id
- 协议命令：cmd, protocol, packet, opcode, handler
- 配置：ini, xml, serverlist, port, env, db_conn
- 数据库：sql, table, persist, record, transaction
- Lua脚本：lua, luabind, execute_script_event, require, npc_script
- 任务系统：quest, newquest, source_xml, condition, trigger, reward
- 经济/充值：bill, charge, consume, point, account, order
- 角色保存：role_save, record, flush, dirty, snapshot
- 区服列表：fl, zone_list, server_select, tempid
- Mini：mini, miniserver, minigame, event, ranking
- 工具链：tools, convert, deploy, rollback, batch_sql
- 风险排查：risk, drift, mismatch, timeout, leak, consistency
