# 主链路检索路由表

- 启动失败：模块 `base/config/super/session/gateway/scene`；关键词 `startup init serverlist port db connect`；level `S/A`；追问：首个报错时间点与服务名。
- 服务注册失败：模块 `super/config/session/gateway/scene`；关键词 `register heartbeat serverlist`；level `S`；追问：哪个服务ID注册失败。
- 登录失败：模块 `fl/gateway/session/bill`；关键词 `login auth tempid account token`；level `S/A`；追问：失败发生在入口、鉴权还是扣费。
- 网关转发失败：模块 `gateway/session/scene`；关键词 `forward dispatch connection protocol`；level `S/A`；追问：命令号与连接状态。
- 进场景失败：模块 `scene/session/gateway/config`；关键词 `enter scene map aoi transfer`；level `S`；追问：地图ID与角色状态。
- 角色保存失败：模块 `record/scene/config/base`；关键词 `save persist sql role`；level `S`；追问：保存触发点与SQL报错。
- 充值/扣费异常：模块 `bill/scene/record`；关键词 `charge consume point account`；level `S`；追问：订单号、角色ID、余额前后值。
- 区服列表异常：模块 `fl/super/config`；关键词 `serverlist zone list`；level `A`；追问：目标区服是否注册可见。
- Mini 小游戏异常：模块 `mini/scene/script/config`；关键词 `mini game event reward`；level `A/B`；追问：具体玩法与事件入口。
- 配置漂移：模块 `config/super/all`；关键词 `config drift xml ini db`；level `S/A`；追问：哪次发布后出现。
- Lua 脚本异常：模块 `script/newquest/quest/scene`；关键词 `lua execute_script_event require`；level `S/A`；追问：脚本文件与调用堆栈。
- 任务不推进：模块 `quest/newquest/script/scene`；关键词 `quest condition trigger npc source xml`；level `S`；追问：任务ID、条件变量、事件名。
- 工具误用/压测风险：模块 `tools/config/db`；关键词 `tool sql convert deploy rollback pressure`；level `S/A`；追问：执行工具名与命令参数。
