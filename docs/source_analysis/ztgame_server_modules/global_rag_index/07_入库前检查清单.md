# 入库前检查清单

1. 文件路径检查：所有 `path` 必须存在或标注“待确认”。
2. JSONL 格式检查：每行可独立 `json.loads`。
3. 重复 path 检查：同 module+path+level 去重。
4. level 检查：仅允许 `S/A/B/C`（异常记录到待修复）。
5. collection 分配检查：core/config/script_quest/tools_ops/risk 分配正确。
6. 中文编码检查：统一 UTF-8，无乱码。
7. docs/docs 错误路径检查：避免重复前缀路径。
8. manifest 行数统计：子 manifest 汇总行数需等于全局 manifest 行数。
9. S级文档是否存在：每个模块至少 1 条 S 级条目；若无则标“待确认”。
