# 脚本二开建议
- 安全新增函数：优先新增只读查询型 `def`，避免直接资产改写接口。
- 安全新增属性：优先经包装函数暴露，不直接暴露裸成员或敏感指针。
- 不建议改动：`execute_script_event` 基础模板、`current_user` 语义、`ScriptQuest` 索引约定。
- 热更边界：当前是 `reloadVM()` 全量重载 `newquest/quest.lua`，非细粒度热更新。
- 灰度测试：建议分服或白名单账号验证 enter/quit/NPC/任务完成全链路。
- 回滚策略：脚本入口版本化（quest.lua + npc目录）并保留可快速切换旧包。

待确认：是否存在线上脚本动态下发机制（需查运维部署脚本）。
