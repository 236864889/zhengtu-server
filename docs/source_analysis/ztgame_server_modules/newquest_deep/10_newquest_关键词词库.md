# 关键词词库

- 入口：LUA_PATH, quest.lua, enter, quit, die
- NPC脚本：npc_*, visit_*, state_*, kill_*
- 任务XML：quests.xml, event source, on_visit, on_kill, on_enter
- 对话：show_dialog, menu_*, TaskDialog
- 奖励：add_exp, add_item, add_money, bonus
- 道具经济：remove_item, bind_money, point
- 传送：teleport, change_map, x, y
- 刷怪：refresh_npc, summon_npc, kill_boos
- 编码风险：GBK, UTF-8, CRLF, 乱码
- 二开模板：新增NPC, 新增任务, 灰度, 回滚
- 异常排查：luabind::error, FATAL ERROR, require failed
