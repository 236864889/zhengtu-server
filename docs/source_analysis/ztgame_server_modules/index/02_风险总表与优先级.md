# 风险总表与优先级

| 风险类型 | 涉及路径 | 风险描述 | 影响范围 | 优先级 | 当前文档证据 | 建议处理方式 | 是否需要服务器实测 |
|---|---|---|---|---|---|---|---|
| `kill -9` 停服 | `ztgame/stop.sh` | 强杀导致状态/落盘不完整 | 全服 | P0 | `stop.sh` + `tools_entry_deep/04` | 改 TERM/超时/分级停服脚本 | 是 |
| UserServer 待确认 | 服务目录缺失 | 文档提及但仓库无目录，部署依赖不明 | 登录链/会话链 | P0 | `remaining_deep_candidates/04` | 建 issue + 部署清单对账 | 是 |
| 硬编码敏感配置 | scripts/config/tutorials | 账号、地址、口令可能外露 | 安全合规 | P0 | `tutorials_inventory/review/01/02` | 去敏与外置化策略 | 否（静态可先做） |
| tools 高副作用入口 | `ztgame/tools` | SQL/发布/回滚工具误操作风险高 | 数据+发布链 | P0 | `tools_deep/06` `tools_entry_deep/04` | 分级执行、只读前置检查 | 部分需要 |
| test MySQL 写库风险 | `ztgame/test` | 样例可能直连并写库 | 数据库 | P1 | `test_deep/04/06` | 全量 dry-run 封装 | 否 |
| ztgame.dat/登录器联调 | `ztgame_dat` `launcher_reanalysis` | 协议/地址/版本不一致 | 登录与客户端可用性 | P1 | `ztgame_dat/runtime_validation/*` | 按验证方案执行只读检查 | 是 |
| 配置/XML 缺失 | `config_deep` 关联目录 | XML 资源缺失或漂移 | 多服务启动链 | P1 | `config_deep/04/06/07` | 配置完整性校验脚本 | 是 |
| Lua/luabind 编译风险 | `script_deep` | 绑定差异导致脚本不可用 | 场景/任务链 | P1 | `script_deep/01/06` | 绑定清单差异静态比对 | 部分需要 |
| log4cxx 兼容风险 | base & 服务依赖 | 老版本依赖在新环境不稳定 | 日志与进程稳定性 | P2 | `base_deep/04` | 环境版本基线文档化 | 是 |
