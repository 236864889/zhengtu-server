# 01 敏感信息复扫报告

## 扫描命令
`grep -RIn "DB_PASS|SMTP_PASS|EPAY_KEY|EPAY_PID|PASSWORD|PASSWD|授权码|mysql:host|[0-9]{1,3}\.[0-9]{1,3}\.[0-9]{1,3}\.[0-9]{1,3}|qq.com|hhemall.com" 配套官网`

## 复扫结论
- 业务核心配置文件未发现真实 DB/SMTP/EPAY 密钥默认值。
- 剩余命中主要为：
  - 字段名（如 `PASSWD`）
  - 示例文档/测试用例中的变量名
  - 第三方库 RFC 注释
  - 页面中 QQ 链接文本
