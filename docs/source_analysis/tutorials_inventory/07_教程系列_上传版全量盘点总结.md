# 教程系列（`教程系列_上传版`）全量文件夹与文件盘点总结

## 1. 总体规模

- 根目录：`教程系列_上传版`
- 一级分类目录：3 个
  - `服务端说明`
  - `客户端说明`
  - `网络收集教程`
- 全部文件总数：269
- 主要文件类型：
  - `.txt`：226（主体）
  - `.xml`：8
  - `.doc`：6
  - `.chm`：5
  - `.ini`：5
  - 其余为 `.png/.jpg/.xls/.rtf/.tbl` 等少量附件

结论：该教程集是“以文本经验帖为主、夹杂少量配置样例和工具附件”的历史资料包。

## 2. 目录结构与内容重心

## 2.1 `服务端说明`（核心密度最高）

该目录包含大量可直接落地的运维与玩法配置修改资料，子目录覆盖：

- `脚本修改       篇`（含 `升级提示/levelup.xml`）
- `TBL  修改       篇`
- `技能修改        篇/职业和技能修改`
- `服务器7.0-7.2编译教程`
- `TBL互转XML工具`
- `改的文件`（配置示例）
- `一区和二区ip设置`（图文）
- `NPC相关ID  和修改`

内容主题可归为：

1. **脚本与任务链改造**：NPC 对话、任务奖励、拉镖、福利姐姐、地图刷怪、国家任务等。
2. **数值与物品体系修改**：装备、魂魄石、神圣标识、爆率、绑定属性、等级经验表。
3. **服务端运维基础**：Linux 时间、防火墙、启动命令、缺库安装、数据库表说明。
4. **版本编译与部署**：7.0~7.2 编译说明及常见依赖缺失处理。

## 2.2 `客户端说明`（资源结构与表现层）

主要聚焦客户端资源包（PAK/TBL）与表现资产映射：

- 新装备/时装、新技能/特效的添加说明
- 客户端 PAK 结构解析（多份不同版本文档）
- NPC PAK、weaponrPAK、称号图片映射
- 特定补丁颜色、怪物颜色类型、王城 NPC 坐标

定位：用于支撑“显示效果、资源映射、客户端素材一致性”的修改。

## 2.3 `网络收集教程`（资料仓与工具混合区）

目录内有一个高密度子目录 `教程`（100+ 文件），聚合了：

- 架设与外网教程（Linux/Windows/宝塔/局域网）
- GM 命令、数据库表分析、任务注解
- 装备与技能修改、地图代码、国家系统改动
- 多种历史文档格式（`.doc/.chm/.mht/.xls`）
- 工具附件（如 `L端的GM工具全套`、`TBL编辑器`）

定位：偏“社区经验收集”，信息覆盖广，但质量与时效差异大。

## 3. 重复与交叉情况

盘点显示多个主题在三大目录间有明显重复，例如：

- `征途NPC出售物品`
- `魂魄石修改及添加BOSS掉落`
- `乾坤套完美添加方法`
- `技能修改/技能代码`
- `地图代码`
- `修改可以注册的国家数量`

这说明当前资料是“多来源合并”而非统一编排，优点是覆盖全面，缺点是检索成本高、版本冲突风险高。

## 4. 可用性评估（面向整理与二次出版）

1. **高可用层（优先保留）**
   - 带明确路径、文件名、字段说明的配置/脚本文档。
   - 带示例 XML/TBL 的可复现操作说明。

2. **中可用层（需要校验）**
   - 纯经验贴（如“某 BUG 解决方法”），需要与当前代码/版本交叉验证。
   - 旧版 Win1.1、1.10 相关文档，需要标注版本前提。

3. **低可用层（归档为历史）**
   - 格式老旧且上下文缺失的外链型材料（部分 CHM/MHT）。
   - 内容高度重复或命名不清的“新建文本文档*”。

## 5. 建议的整理输出方式

建议将 `教程系列_上传版` 进一步沉淀为“统一教程手册”，按以下骨架重组：

1. 环境与部署（Linux/依赖/数据库/启动）
2. 服务端配置（脚本、任务、刷怪、国家系统）
3. 数值体系（技能、装备、爆率、经验）
4. 客户端资源（PAK/TBL、特效、称号、素材映射）
5. GM 与排障（命令、常见报错、快速回滚）
6. 附录（历史资料与版本差异索引）

这样可以把“历史资料包”转成“可检索、可执行、可维护”的工程化文档资产。
