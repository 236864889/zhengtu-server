# 账号登录与会话源码走读模板（Gateway / Session / 登录器联动）

> 目的：帮助天枢团队建立“登录器 -> Gateway -> Session -> Scenes”全链路认知。  
> 范围：源码走读模板，不涉及重构改造。

## 1. 登录与会话主链路（总览）

```text
登录器选择区服并启动客户端
  -> 客户端发起连接请求
    -> GatewayServer 接入与转发
      -> SessionServer 账号认证/会话维护
        -> ScenesServer 角色入场景
```

核心关注：
1. 连接建立时机
2. 认证校验节点
3. 会话状态保存位置
4. 异常断线恢复路径

## 3. 推荐走读顺序

1. 登录器入口：`Program.cs` / `Form1.cs`（区服与启动参数）
2. `GatewayServer`：连接接入与消息转发
3. `SessionServer`：账号认证与会话管理
4. `ScenesServer`：进场景确认与在线状态
5. 回到客户端验证状态反馈是否一致

---

## 4. 必做样本（首轮）

1. 正常登录成功链路（一次完整成功）
2. 错误口令/认证失败链路（失败分支）
3. 断线重连链路（恢复分支）

每个样本都要完整填完第 2 节模板。

## 5. 验收标准（天枢团队）

满足以下全部条件才算通过：

1. 能给出登录链路文件级调用图。
2. 能明确会话状态的写入与读取位置。
3. 能解释 3 个异常分支的处理策略。
4. 能给出至少 1 条可复现实验记录。
5. 能指出 3 个高风险点并给出原因。

---

## 6. 常见误区（提前规避）

1. 只看登录器，不看网关与会话服务。
2. 只看成功路径，不看超时与重连。
3. 只看日志文字，不核对状态值变化。
4. 只看单文件函数，不画跨进程调用关系。
