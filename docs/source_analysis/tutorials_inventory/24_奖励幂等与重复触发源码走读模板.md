# 奖励幂等与重复触发源码走读模板

## 1. 目标
识别奖励链路中的重复触发风险，确认幂等保护是否完整。

## 2. 走读范围
- 任务奖励
- 活动奖励
- 充值/补偿点数奖励

## 4. 必查问题
1. 同一请求重复到达是否二次发奖。
2. 并发触发是否会绕过幂等。
3. 失败重试是否造成重复执行。
4. 日志/数据库能否定位重复触发来源。

## 5. 验收
- 至少完成 3 个场景的幂等核对。
- 每个场景给出“防重判断代码位置 + SQL/日志证据”。
