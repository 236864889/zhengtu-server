# ztgame.dat 客户端源码调用链导图（UI / 渲染 / 技能 / 资源）

> 目的：帮助天枢团队在 `ztgame.dat` 中建立“客户端表现链路”认知。  
> 范围：只做源码阅读导图，不涉及重构方案。

## 1. 客户端表现主链（总览）

```text
用户输入(UI)
  -> 客户端逻辑(Client)
    -> 引擎层(engine)
      -> 渲染层(RenderD3D)
        -> 资源层(PAK/贴图/模型/特效)
          -> 屏幕呈现
```

重点目录映射：

- UI：`ztgame.dat/gui/`
- 客户端逻辑：`ztgame.dat/Client/`
- 引擎基础：`ztgame.dat/engine/`
- 渲染：`ztgame.dat/RenderD3D/`
- 技能表现：`ztgame.dat/Magic/`

---

## 2. UI 调用链（交互入口）

## 2.1 建议阅读入口

- `ztgame.dat/gui/include/`
- `ztgame.dat/gui/source/`

优先关注：

- 按钮/列表/对话框事件如何触发客户端业务逻辑。
- UI 状态变化与网络状态刷新如何绑定。

## 2.2 阅读检查点

1. 一个按钮点击最终调用到哪个客户端模块。
2. UI刷新是主动轮询还是事件驱动。
3. 异常状态（网络断开、资源缺失）如何反馈到界面。

---

## 3. 渲染调用链（引擎到画面）

## 3.1 建议阅读入口

- `ztgame.dat/engine/`
- `ztgame.dat/RenderD3D/`

先回答：

1. 场景帧更新主循环在哪里。
2. 相机、对象、特效提交到渲染队列的路径。
3. 资源加载失败时的兜底逻辑。

## 3.2 常见风险点

- 渲染调用顺序改动导致黑屏/闪烁。
- 资源释放时机错误导致崩溃或内存上涨。
- 状态切换（登录场景 -> 游戏场景）时上下文残留。

---

## 4. 技能与特效调用链（Magic）

## 4.1 建议阅读入口

- `ztgame.dat/Magic/`
- `ztgame.dat/Client/` 中技能触发相关逻辑

建议按“一个技能”为样本走读：

```text
技能输入
  -> 客户端技能触发判断
    -> 特效参数/资源定位
      -> 渲染提交
        -> 表现结束与状态回收
```

## 4.2 阅读检查点

1. 技能ID如何映射到表现资源。
2. 特效生命周期由谁管理。
3. 技能中断/取消时是否有清理逻辑。

---

## 5. 资源加载链（资源可用性）

## 5.1 重点目录

- `ztgame.dat/Client/`
- `ztgame.dat/engine/`
- `ztgame.dat/PakTest/`、`EncDec/`、`MergeTga/`（工具链）

## 5.2 阅读检查点

1. 资源路径解析规则在哪里。
2. 资源缓存命中/失效策略在哪里。
3. 资源损坏时客户端行为（崩溃/降级/提示）。

---

## 6. 天枢团队最小走读任务单

## Task A：UI链路样本

- 选择一个 UI 控件（如按钮）
- 输出：`控件事件 -> 业务逻辑 -> 结果刷新` 路径

## Task B：渲染链路样本

- 选择一个场景对象
- 输出：`对象更新 -> 渲染提交 -> 显示结果` 路径

## Task C：技能链路样本

- 选择一个技能
- 输出：`技能触发 -> 特效加载 -> 回收` 路径

## Task D：资源链路样本

- 选择一个资源文件
- 输出：`路径解析 -> 加载 -> 缓存 -> 失败处理` 路径
