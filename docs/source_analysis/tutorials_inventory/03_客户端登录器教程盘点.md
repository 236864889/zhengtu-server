## 覆盖情况
- `ztgame.dat`：有大量历史说明与新近 runtime_validation 文档。
- `ztgame.exe`：在 runtime 验证文档中有主程序识别与启动链路验证内容。
- `config.ini`：有专项验证文档（如 `P0_01_config_ini字段验证.md`）。
- 登录器：有 C# 登录器联调方案、WinForms 工程与旧版修改说明。
- `servers.json`：有相关联调提及，但散落在验证文档中，缺少单一“配置说明页”。
- VS2015：历史教程有提及，但需要和当前工程实际可编译性分离标注。
- 资源检查/启动链路：`runtime_validation` 覆盖较完整。

## 可用性判定
- 高价值（可纳入手册）：`runtime_validation` + `launcher_reanalysis` 的链路验证文档。
- 中价值（需修订）：`教程系列_上传版/客户端说明` 中 PAK/TBL 类文本，可作为术语参考，不宜作为操作 SOP。
- 低价值/高风险：旧“登录器修改.doc”“破解向导”类网络收集资料。
