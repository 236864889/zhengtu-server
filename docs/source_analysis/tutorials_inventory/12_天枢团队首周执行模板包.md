# 天枢团队首周执行模板包（可直接开工）

## 1. 目标

为天枢团队提供“拿来即用”的执行模板，避免只写结论、缺证据、难复盘。

## 2. 模板清单

1. `docs/templates/tianshu/周进展报告模板.md`
2. `docs/templates/tianshu/回归结果清单模板.md`
3. `docs/templates/tianshu/风险台账模板.md`
4. `docs/templates/tianshu/变更索引模板.md`

## 3. 建议使用方式

- 每周一复制模板创建本周文档。
- 每完成一项改动，立即更新“变更索引模板”。
- 每次回归结束，当日落地“回归结果清单”。
- 每周评审前统一更新“风险台账”。

## 4. 首周排班建议

- Day1：仓库基线扫描（凭据/编码/关键链路可运行性）
- Day2：支付回调四场景回归
- Day3：口令机制核验（只读）
- Day4：登录器配置降级方案评估
- Day5：周报汇总 + 风险复盘 + 下周任务拆解

## 5. 最小交付标准

1. 所有任务必须有命令与证据。
2. 所有风险必须有负责人与关闭时间。
3. 所有变更必须有回滚说明。
4. 所有回归必须有“预期 vs 实际”对照。

满足以上 4 条，天枢团队即可进入稳定的周迭代节奏。
