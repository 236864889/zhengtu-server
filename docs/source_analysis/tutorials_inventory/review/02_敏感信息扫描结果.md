# 敏感信息扫描结果（静态）

## 扫描范围
- `配套官网`
- `docs/source_analysis/tutorials_inventory`
- `docs/templates/tianshu`

## 扫描命令
- `grep -RIn "DB_PASS|SMTP_PASS|EPAY_KEY|EPAY_PID|PASSWORD|PASSWD|授权码|mysql:host|IPv4|qq.com|hhemall.com" ...`

## 命中分类

### A. 疑似真实敏感信息（高风险）
- `配套官网/db.php`：DB_PASS、SMTP_PASS、EPAY_KEY、EPAY_PID、hhemall.com、公网 IP。
- `配套官网/lottery.php`、`balance_query.php`、`cdk_recharge.php`、`register_compat.php`：含 DB 默认口令/IP 回退值。

### B. 占位/说明性命中（中低风险）
- 示例邮箱、注释中的 SMTP 授权码说明、文案中的 `123@qq.com`。
- 第三方库（如 PHPMailer）的 RFC 文本、示例 IP 说明。

### C. 真实风险命中
- 存在明文数据库口令与支付密钥，且处于可执行配置代码路径。

## 必须修复项
1. `db.php` 改为环境变量加载，删除所有真实凭据默认值。
2. 清理其他 PHP 文件中的硬编码 DB 回退口令/IP。
3. 将支付相关 key/pid/domain 改为占位值与 `.env` 注入。

## 建议修复项
1. 增加 `.env.example`（仅占位）。
2. 增加 pre-commit/CI secret scan。
3. 统一 `config/bootstrap`，禁止业务文件自带默认明文凭据。
