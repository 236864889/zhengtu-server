# 00_项目总览

项目结构与服务分层总览，供RAG入口检索。

## 事实来源
- `ztgame/Makefile`：定义 `SUB_DIRS`、编译参数和发布复制目标。
- `ztgame/start.sh`、`ztgame/start1.sh`、`ztgame/stop.sh`：体现启动/停止顺序。
- 各子目录 `Makefile`：定义二进制目标与依赖库。
- `ztgame/script/lua.h`：Lua版本信息。
- `ztgame/base/*.h/*.cpp`：网络、数据库、日志基础组件。

## 待确认范围
- 端口号、具体数据库库名/表结构、生产部署拓扑在当前仓库中未直接固化，统一标记“待确认”。

## 项目总体结构
- 主源码位于 `ztgame/`，核心服务目录包括 `ScenesServer`、`SessionServer`、`GatewayServer`、`FLServer`、`SuperServer`、`BillServer`、`MiniServer`、`RecordServer`。
- `base/` 提供公共库 `libzebra.a`，多数服务链接该库。
- `Config/`、`quest/`、`newquest/`、根级多个 `*.xml` 构成配置与数据输入层。
