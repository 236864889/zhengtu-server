# 02_编译顺序与产物（v0.2）

## 事实依据
- `ztgame/Makefile` 的 `SUB_DIRS = base/EncDec base MiniServer ScenesServer SessionServer BillServer GatewayServer SuperServer RecordServer FLServer tools`。
- 各子目录 `Makefile` 的 `ALL_TARGETS`、`LIB_*`、`CXXLFLAGS`。

## 编译顺序（按仓库构建链）
1. `base/EncDec`：先构建加解密子库（产物见下）。
2. `base`：构建基础静态库，供全部服务链接。
3. `script`：**不是顶层 `SUB_DIRS` 独立子模块**，但其静态库被服务端链接。
4. 服务端二进制：
   - `MiniServer`
   - `ScenesServer`
   - `SessionServer`
   - `BillServer`
   - `GatewayServer`
   - `SuperServer`
   - `RecordServer`
   - `FLServer`
5. `tools`：运维/调试工具。

## 主要产物清单
- `base/EncDec`：`libencdec.a`（静态库）。
- `base`：`libzebra.a`（静态库）；并在链接链路中出现 `libcrypto.a`（静态库）。
- `script`：`liblua.a`、`libluabind.a`、`liblualib.a`（静态库提供关系，供业务模块链接）。
- 服务端二进制：
  - `MiniServer/MiniServer`
  - `ScenesServer/ScenesServer`
  - `SessionServer/SessionServer`
  - `BillServer/BillServer`
  - `GatewayServer/GatewayServer`
  - `SuperServer/SuperServer`
  - `RecordServer/RecordServer`
  - `FLServer/FLServer`
- `tools`：`zntop`、`zebraclientService`、`datetime`。

## 链接关系重点
- 大多数服务目录通过 `-L../base -lzebra -lencdec` 链接基础库。
- `ScenesServer` 额外通过 `-L../script -llua -lluabind` 引入脚本能力。
