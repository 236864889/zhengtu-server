# 04_服务端模块关系

各服务通过Client/Manager命名体现的关系图。

## 事实来源
- `ztgame/Makefile`：定义 `SUB_DIRS`、编译参数和发布复制目标。
- `ztgame/start.sh`、`ztgame/start1.sh`、`ztgame/stop.sh`：体现启动/停止顺序。
- 各子目录 `Makefile`：定义二进制目标与依赖库。
- `ztgame/script/lua.h`：Lua版本信息。
- `ztgame/base/*.h/*.cpp`：网络、数据库、日志基础组件。

## 待确认范围
- 端口号、具体数据库库名/表结构、生产部署拓扑在当前仓库中未直接固化，统一标记“待确认”。

## 模块关系（基于源码类名）
- `GatewayServer` 含 `SceneClient`、`SessionClient`、`RecordClient`、`BillClient`。
- `ScenesServer` 含 `SessionClient`、`RecordClient`、`MiniClient`。
- `SuperServer` 含 `FLClient`、`RoleregClient`、`InfoClient`。
- `FLServer` 含 `DBAccessClient`、`InfoClient`。
