# 09_下一阶段建议

## 建议执行顺序
1. **先用手册指导一次只读环境检查**：按 v1.1 的来源路径、配置路径、脚本路径逐项核实可用性与一致性。
2. **再执行 base 编译复验**：先验证基础模块可编译与依赖闭环。
3. **再执行主服务编译复验**：按 `SUB_DIRS` 顺序推进，重点盯紧 ScenesServer 链接链路。
4. **再执行启动链路联调**：并行对照 `start.sh` 与 `start1.sh` 双基线，确认最终生产 SOP。
5. **RAG/Qdrant/Embedding 继续后置**：在编译与启动链路稳定后再恢复知识库侧工作。

## 附加建议
- 在进入第 2 步前先完成 UserServer、端口拓扑、停服策略三项 P0 决策。
- 每一步输出独立复验记录，形成可审计闭环。
