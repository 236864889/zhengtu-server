# 14_v1_2修订记录

## 一、修订原因

基于本轮仓库静态检查结论，需要把操作手册从 v1.1 升级到 v1.2，核心目标是纠正任务边界错配：

- 防止把真实环境检查、编译与启停动作错误分配给 Codex；
- 明确 Codex 仅做仓库内静态分析与文档修订；
- 将服务器实测动作系统性迁移到 Claw/SSH/人工任务模板。

## 二、修订文件

1. `docs/operations/征途源码编译部署完整操作手册.md`
2. `docs/operations/附录C_Codex_Claw任务模板.md`
3. `docs/operations/review/14_v1_2修订记录.md`（本文件，新增）

## 三、新增章节与重点变更

### 主手册（v1.2）

- 标题升级为 `# 征途源码编译部署完整操作手册 v1.2`。
- 新增“工具职责边界”章节，明确 Codex 与 Claw/SSH/人工职责。
- 新增 shebang 异常兼容说明：`start.sh` / `stop.sh` 异常时用 `bash` 显式执行。
- 新增 stop.sh 分级停服策略：优先温和停服，`kill -9` 仅兜底。
- 强化 UserServer 说明：源码树未见独立目录，维持“待服务器确认”。
- 修正“下一阶段执行路线”：
  - 仓库静态检查 → Codex；
  - 真实只读环境检查 → Claw/SSH/人工；
  - base 编译复验 → Claw/SSH/人工执行，Codex 仅分析日志。

### 附录C（v1.2）

- 新增“Codex 仓库静态检查任务（仅仓库内）”。
- 新增“服务器/Claw 只读环境检查任务（真实环境）”。
- 新增“base 编译复验任务（真实执行 + 日志回传）”。
- 新增“启动联调任务（真实执行）”。
- 保留并收敛其他排查模板，统一到“Codex只分析、服务器侧执行”的口径。

## 四、边界修正摘要

- Codex 不执行：`gcc/mysql_config/xml2-config/df/ss/make` 等真实环境命令。
- Codex 不执行：服务启动、停服、kill、数据库连接。
- Claw/SSH/人工执行：真实环境检查、编译、启停、联调。
- Codex 仅在拿到日志后给出定位与补丁建议。

## 五、仍待服务器实测项

1. 目标服务器 shebang 兼容性与最终执行方式。
2. `start.sh` 与 `start1.sh` 的生产基线最终选择。
3. `stop.sh` 是否有可用温和停服机制。
4. `UserServer` 是否为现网必需组件。
5. 真实依赖、端口、进程、数据库可达性状态。
6. `make -C base` 与全链路编译的真实结果。

## 六、结论

本次 v1.2 修订后，文档可以作为 **Codex/Claw 分工手册** 使用：

- Codex 负责静态分析与文档输出；
- Claw/SSH/人工负责实机动作与结果回传；
- 双方通过“日志回传 + 静态诊断”闭环协作。
