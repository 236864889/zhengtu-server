# 手册 v1.1 修订建议

## 需要补强的章节
1. 环境与依赖：明确“当前基线”与“历史基线”双轨说明。
2. 编译章节：补齐 `Makefile SUB_DIRS` 顺序、`script` 链接依赖说明、产物校验清单。
3. 启动章节：并列写清 `start.sh` 与 `start1.sh`，不得混写。
4. 客户端/登录器章节：对齐 `runtime_validation` 与 `launcher_reanalysis` 的证据链。
5. 故障章节：吸收 `10_已修复编译问题记录.md` 的全部修复项与定位方式。

## 需要增加成功判定的命令/步骤
1. 每个编译步骤增加“预期产物文件存在判定”。
2. 每个启动步骤增加“进程存在 + 日志关键字”双判定。
3. 配置/数据库步骤增加“配置可读性/连通性判定”（仅写检查方法，不执行高风险操作）。

## 历史教程降级建议
1. 将 C/D 级资料统一收敛到“历史参考附录”，禁止写入主流程。
2. B 级仅保留事实线索，不保留原命令。
3. 对“破解类、不可验证类”内容做显式禁用标签。

## 是否需要新增“快速启动版”
- 建议：**需要**。
- 目标：为已具备环境的工程同学提供最短路径；同时强制附带风险与回滚入口。

## 是否需要新增“一键检查脚本”
- 建议：**需要**（但脚本仅做只读检查）。
- 内容：路径存在性、关键文件可读性、编译产物存在性、启动脚本差异提示。
