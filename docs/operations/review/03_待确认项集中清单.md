# 待确认项集中清单

## P0（发布前必须确认）
1. 当前正式 OS 基线版本（CentOS 6.5 仅历史基线还是仍为主线）。
2. 生产端口号与完整拓扑（外网入口、内网服务互联、数据库访问域）。
3. UserServer 是否仍为部署必需组件。
4. 服务日志实际落盘目录（是否仍有 `/tmp/*.log*` 行为，及长期日志目录）。
5. 数据库库名/表名最终权威来源（配置文件、SQL 初始化脚本、运维文档）。
6. `gd` / `jpeg` 在当前构建链是否仍为必需（按模块逐项确认）。
7. 启动顺序最终采用 `start.sh` 还是 `start1.sh` 作为正式 SOP。

## P1（v1.1 建议确认）
1. 是否存在部署态二进制目录与源码目录差异（影响 `./SuperServer` vs `SuperServer/SuperServer` 启动写法）。
2. `roleRegServer`、`InfoServer` 在现网是否仍保留（`stop.sh` 仍尝试杀进程）。
3. 客户端/登录器联调过程中，runtime_validation 与 launcher_reanalysis 的优先级顺序。
