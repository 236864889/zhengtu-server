# 入库规则（v0.2）

## 阶段结论
- 当前历史 `v0.1` 文档模板化较高，**不建议直接整体入库**。
- `v0.2` 修订后，建议优先入库 `docs/rag_sources/`。

## 入库优先级
1. **第一优先**：`docs/rag_sources/*.md`（专题化文档）。
2. **第二优先**：`docs/rag_sources/modules/*.md`（模块化文档）。
3. **辅助索引**：仓库各目录 `README.md`，仅作导航，不作为首要语义来源。

## 过滤规则
- 低价值模板段落不入库（如无事实支撑的泛化描述）。
- 含“待确认”的条目允许入库，但需保留“待确认”标签，避免当成确定事实。
- 与 Makefile/脚本/配置可对齐的事实段优先入库。

## 切片建议
- 每片 500~1200 中文字，重叠 80~150 字。
- 按“编译链、启动链、模块关系、风险清单”做语义切分。

## 维护规则
- 若源码或构建脚本变化，先更新 `docs/rag_sources` 再重建向量。
