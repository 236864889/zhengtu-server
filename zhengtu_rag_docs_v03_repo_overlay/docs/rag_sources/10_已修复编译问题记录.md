# 10_已修复编译问题记录（v0.2）

## 已确认修复事实
1. `base` 模块已生成：`libzebra.a`、`libencdec.a`、`libcrypto.a`。
2. `script` 目录不是独立 make 子模块，主要提供 `liblua.a`、`libluabind.a`、`liblualib.a` 给其他模块链接。
3. 已修复 `zMisc.h` 中 `zMisc::getAllNum` 多余限定问题。
4. 已修复 `zMysqlDBConnPool.cpp` 中旧 GCC 扩展最小值运算符问题。
5. 已修复 `zLogger.h` 的 log4cxx 0.10.0 兼容问题。
6. 已修复 `zSocket.h` 缺少 `vector`、`ByteBuffer` 命名冲突、模板构造函数特化问题。
7. 已修复 `zSocket.cpp` 中 `goto` 跳过 `retcode` 初始化问题。
8. `base` 已成功编译通过，下一步重点是 `ScenesServer` / 其他服务的链接与运行验证。

## 影响范围
- 以上修复集中在基础设施层（socket、logger、db pool、通用工具），会影响所有服务二进制链接与运行稳定性。

## 下一步验证清单
1. 逐个服务执行链接验证：`MiniServer`、`ScenesServer`、`SessionServer`、`BillServer`、`GatewayServer`、`SuperServer`、`RecordServer`、`FLServer`。
2. 启动验证时按 `start1.sh` 顺序执行，记录首个失败模块与日志关键字。
3. 针对 `ScenesServer` 重点核查 Lua 绑定与配置加载链。
